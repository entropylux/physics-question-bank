# 物理题库与解答

按11门物理课程组织的题库，包含知识点讲义、原题图片、逐题推导、132道教学自编练习、四轮经典与近代分场练习卷，以及4套四大力学专题练习。适合课程学习、自测与复习。

## 阅读方式

下载整个仓库后，用浏览器打开 **index.html**。公式字体、样式和图片均保存在本地，可以离线阅读。在GitHub中可直接阅读各科Markdown正文。

- [原题解答总览](官方题库解答总览.md)：按科目查找题目、解答及题面缺项说明。
- [四轮分场练习卷](分场练习卷/README.md)：每轮各一张经典卷和近代卷，共八张。经典包含力、电、热、光、分析力学、电动力学；近代包含高量、量子、统计物理、统计力学、相对论。每张100分、建议180分钟，答案统一附在全卷题目后。
- [4套四大力学专题练习](专项练习卷/README.md)：保留原有跨科训练，每套7题、100分，量子与热统合计80分。可用于按薄弱知识点加练。
- [使用说明](使用说明.md)：学习路线与题库使用方法。

## 资料说明

原题图片保留其原有题号、图示、署名和来源信息；题意摘要及解答另行整理。题库中包含教材题、课程练习和不同来源的试题，部分条目为配套解答页。教学自编题均明确标注，原题缺失问项的条目单独说明。

第三方KaTeX资源许可证见[阅读资源/katex/LICENSE](阅读资源/katex/LICENSE)。原始资料的权利仍归各自权利人所有。

## 重新生成阅读版

安装Node.js与本目录package.json中的依赖后，运行 `npm run build` 和 `npm run verify`。生成PDF可运行 `npm run pdf`；浏览器程序路径可通过 `BROWSER_EXECUTABLE` 环境变量指定。
